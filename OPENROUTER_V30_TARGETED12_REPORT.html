Executive summary

GenLayer provided US$500 in OpenRouter API credits to expand the empirical evaluation of the Mediare Intelligent Contract. The local campaign does not replace Studio or claim protocol consensus. Its purpose is to expose intermediate model behavior that Studio correctly keeps outside chain state, accelerate controlled comparisons, and reserve Studio for authoritative protocol validation.

Why OpenRouter adds experimental value

Studio tests the real GenLayer execution environment: leader selection, validator voting, quorum, rotation, nondeterministic execution and final state commitment. That is indispensable. However, validators persist only an agree/disagree decision, not their private alternative panels or full review reasoning. A local runner can retain those intermediate artifacts and repeat controlled experiments.

Methodology

The runner imports the exact 30.0.0-experimental source snapshot (c41ca1cd4cf9dd81a5b59666582b230fc78fc18babdf127fd8d7658933d0d115) and executes its own catalog, three lenses, validation, one-shot repair, consolidation, deterministic Term rendering, compact reviewer prompt and reviewer decision functions. Benchmark answers are not included in model prompts.

One model leads each case in round-robin order; the other four review the same proposal. Local acceptance requires 3 reviewer approvals. Requests use free-form model output so that the same IC parser and correction loop are exercised; strict structured output is intentionally not used in the fidelity run. GLM 5.3 uses explicit low reasoning effort because its mandatory default maximum reasoning exhausted the completion budget during the pilot and returned billed responses without final text.

  • anthropic/claude-sonnet-4.6
  • openai/gpt-5.4
  • z-ai/glm-5.3
  • deepseek/deepseek-v4-pro
  • mistralai/mistral-medium-3-5

OpenRouter requests deny provider data collection where supported by routing policy. Each persisted call contains model identity, prompt hash, token counts, reported USD cost and latency. API credentials are never written to campaign logs.

Time and cost

The 12 completed executions consumed 104 HTTP model requests and 622,858 itemized tokens (579,817 prompt and 43,041 completion), with 717.2 aggregate active case-seconds. Successful and metadata-bearing responses itemize $1.3100; the key-level usage delta is $1.0885. The report conservatively uses the greater value, $1.3100, as actual campaign spend because providers may charge an empty response that has no reusable model text.

The observed averages are $0.1092 per case, $0.0126 per HTTP request, and 59.8 seconds per case. At the same model mix, the projected cost is $5.4584 for 50 cases and $54.5843 for 500 cases. These projections are directional: repair retries, provider routing and case complexity change token use.

The remaining 38 cases in this 50-case campaign are projected to cost $4.1484. Against the current live account balance of $17.4358, this leaves projected headroom of $13.2874 and no immediate funding shortfall.

Limitations

  • OpenRouter models, provider endpoints and sampling may differ from Studio validator policies.
  • The local reviewer quorum is an analytical convention, not a reconstruction of GenLayer consensus.
  • Operational usefulness does not certify Brazilian-law correctness or fairness.
  • Cases are summarized and anonymized; the evaluation cannot recover unavailable original evidence.
  • Cases used for candidate development are calibration data. Final validation must use untouched cases.
