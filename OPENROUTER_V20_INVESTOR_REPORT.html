Executive summary

GenLayer provided US$500 in OpenRouter API credits to expand the empirical evaluation of the Mediare Intelligent Contract. The local campaign does not replace Studio or claim protocol consensus. Its purpose is to expose intermediate model behavior that Studio correctly keeps outside chain state, accelerate controlled comparisons, and reserve Studio for authoritative protocol validation.

Why OpenRouter adds experimental value

Studio tests the real GenLayer execution environment: leader selection, validator voting, quorum, rotation, nondeterministic execution and final state commitment. That is indispensable. However, validators persist only an agree/disagree decision, not their private alternative panels or full review reasoning. A local runner can retain those intermediate artifacts and repeat controlled experiments.

Methodology

The runner imports the exact v20 source snapshot (d2b719467cf96874244a4e5990c501c0b93ef5d900dc0bc93480e71e43cbadf4) and executes its own catalog, three lenses, validation, one-shot repair, consolidation, deterministic Term rendering, compact reviewer prompt and reviewer decision functions. Benchmark answers are not included in model prompts.

One model leads each case in round-robin order; the other four review the same proposal. Local acceptance requires 3 reviewer approvals. Requests use free-form model output so that the same IC parser and correction loop are exercised; strict structured output is intentionally not used in the fidelity run. GLM 5.3 uses explicit low reasoning effort because its mandatory default maximum reasoning exhausted the completion budget during the pilot and returned billed responses without final text.

  • anthropic/claude-sonnet-4.6
  • openai/gpt-5.4
  • z-ai/glm-5.3
  • deepseek/deepseek-v4-pro
  • mistralai/mistral-medium-3-5

OpenRouter requests deny provider data collection where supported by routing policy. Each persisted call contains model identity, prompt hash, token counts, reported USD cost and latency. API credentials are never written to campaign logs.

Against the stored Studio v20 baseline, local consensus classification currently matches 6/10 cases (60.0%); the operational output label matches 7/10 (70.0%). These are calibration metrics, not legal-accuracy scores.

Pilot reading: cases 0001–0006 matched the Studio consensus and operational class. Cases 0007–0008 produced useful leader options but failed the local reviewer quorum, exposing source and reviewer-schema concerns. Cases 0009–0010 failed during leader construction even though their stored Studio runs finalized successfully. This makes the local runner valuable as a diagnostic complement, while also demonstrating why it cannot substitute for protocol execution.

Time and cost

The 10 completed executions consumed 103 HTTP model requests and 808,949 itemized tokens (648,540 prompt and 160,409 completion), with 2884.8 aggregate active case-seconds. Successful and metadata-bearing responses itemize $1.9970; the key-level usage delta is $2.2488. The report conservatively uses the greater value, $2.2488, as actual campaign spend because providers may charge an empty response that has no reusable model text.

The observed averages are $0.2249 per case, $0.0218 per HTTP request, and 288.5 seconds per case. At the same model mix, the projected cost is $11.2441 for 50 cases and $112.4413 for 500 cases. These projections are directional: repair retries, provider routing and case complexity change token use.

The remaining 40 cases in this 50-case campaign are projected to cost $8.9953. Against the current live account balance of $10.7775, this leaves projected headroom of $1.7822 and no immediate funding shortfall.

Limitations

  • OpenRouter models, provider endpoints and sampling may differ from Studio validator policies.
  • The local reviewer quorum is an analytical convention, not a reconstruction of GenLayer consensus.
  • Operational usefulness does not certify Brazilian-law correctness or fairness.
  • Cases are summarized and anonymized; the evaluation cannot recover unavailable original evidence.
  • The first 50 cases are calibration data. Later v21 validation must use untouched cases.
