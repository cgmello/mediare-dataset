# Ícones oficiais da AWS

Ícones extraídos sem alteração do pacote oficial AWS Architecture Icons, edição 31/07/2026.

Fonte: https://aws.amazon.com/architecture/icons/

O arquivo `manifest.json` registra o pacote de origem, caminho original e SHA-256 de cada SVG.
As cores e formas originais são preservadas. Os arquivos são incorporados ao diagrama como imagens SVG, sem acesso remoto durante a leitura.

Ícones e marcas pertencem à Amazon Web Services; a arquitetura representada é uma proposta da Mediare.
